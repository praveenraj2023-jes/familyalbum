# Family Album Website (Free Path)

This version is fully free-hostable using:

- Netlify (frontend hosting)
- Supabase (database + auth)

## Features

- Public users can only view albums on `/`
- Only admin can login on `/admin` and add albums
- Portrait-first mobile UX for all age groups

## 1) Supabase setup

Create a new project in [Supabase](https://supabase.com/), then run this SQL in **SQL Editor**:

```sql
create table if not exists public.albums (
  id bigint generated by default as identity primary key,
  title text not null,
  description text not null default 'No description provided.',
  google_photos_url text not null,
  cover_image text not null,
  created_at timestamptz not null default now()
);

alter table public.albums enable row level security;

drop policy if exists "public can read albums" on public.albums;
create policy "public can read albums"
on public.albums
for select
to anon, authenticated
using (true);

drop policy if exists "authenticated can insert albums" on public.albums;
create policy "authenticated can insert albums"
on public.albums
for insert
to authenticated
with check (true);
```

## 2) Create admin user

In Supabase dashboard:

1. Go to **Authentication** -> **Users**
2. Click **Add user**
3. Create your admin email and password

Use this email/password on `/admin`.

## 3) Configure frontend keys

Edit `public/config.js`:

- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`

Get both values from Supabase:
**Project Settings** -> **API**.

## 4) Test locally

Open `public/index.html` directly in browser, or run any static server.

## 5) Deploy to Netlify (free)

1. Push repository to GitHub
2. In [Netlify](https://app.netlify.com/): **Add new site** -> **Import from Git**
3. Choose this repository
4. Netlify uses `netlify.toml` and publishes `public/`
5. Done

Routes:

- Public: `https://your-site.netlify.app/`
- Admin: `https://your-site.netlify.app/admin`
